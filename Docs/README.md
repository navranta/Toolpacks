# Docs

Reference material for the build.

| file | what it is |
|---|---|
| `GO_TARGETS.md` | `GOOS`/`GOARCH` pairs Go can target |
| `NIX_TARGETS.txt` | nixpkgs cross-compilation targets |
| `RUST_TARGETS.txt` | `rustup target list` |
| `TODO.md` | open work |

These are static reference snapshots. They were previously regenerated by a
workflow step that also pushed to an external bucket; that step is gone, so
refresh them by hand if a toolchain moves.

`ZIG_TARGETS.txt` was removed along with the Zig toolchain — no in-scope
recipe uses Zig.

For how the build works, see the [main README](../README.md).
